# Задача 1. «Математический модуль»

**Что нужно сделать**: создать файл `math_utils.py` с набором математических функций и файл `main.py`, который их использует.

## Обязательное задание

В файле `math_utils.py` определи следующие функции:

1. `factorial(n)` - возвращает факториал числа n через рекурсию.

    - Базовый случай: n == 0 или n == 1 → вернуть 1.
    - Рекурсивный шаг: n * factorial(n - 1).
    - Если n < 0 — вернуть None (факториал не определён).

2. `fibonacci(n)` - возвращает ``n`-е число Фибоначчи через рекурсию.

     - `fib(0) = 0`, `fib(1) = 1`, `fib(n) = fib(n-1) + fib(n-2)`.

3. `is_prime(n)` - возвращает `True/False`, является ли число простым. Реализуй без рекурсии (обычный цикл).

4. `gcd(a, b)` - наибольший общий делитель через рекурсию (алгоритм Евклида).

    - Базовый случай: `b == 0` - вернуть a.
    - Рекурсивный шаг: `gcd(b, a % b)`.
5. power(base, exp)` — возведение в степень через рекурсию.
    - `power(base, 0) = 1`.
    - Для чётного exp: `power(base, exp//2) ** 2`.
    - Для нечётного: `base * power(base, exp - 1)`.

## В файле main.py:

- Импортировать модуль (`import math_utils`).
- Запросить у пользователя число `n`.
- Вывести результаты всех функций с пояснениями.

Пример работы:

```text
Введите число: 5
5! = 120
fib(5) = 5
5 — простое? Да
gcd(5, 12) = 1
2^5 = 32
```
