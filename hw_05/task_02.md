# Задача 2. «Конвертер величин»

**Что нужно сделать**: написать программу-конвертер, которая переводит значения между разными единицами измерения. Вся логика должна быть разбита на небольшие функции.

## Обязательное задание

### Порядок работы программы:

- Вывести меню доступных конвертаций:

```text
1. Километры -> мили
2. Мили -> километры
3. Цельсий -> Фаренгейт
4. Фаренгейт -> Цельсий
5. Килограммы -> фунты
6. Фунты -> килограммы
0. Выход
```
- Запросить у пользователя номер пункта и значение.
- Вывести результат с пояснением.
- Повторять меню, пока пользователь не выберет 0.

### Требования к структуре кода:

Для каждой конвертации - отдельная функция:

- `km_to_miles(km)` - 1 км ≈ 0.621371 мили;
- `miles_to_km(miles)`;
- `celsius_to_fahrenheit(c)` - формула `c * 9/5 + 32`;
- `fahrenheit_to_celsius(f)` - формула `(f - 32) * 5/9`;
- `kg_to_pounds(kg)` - 1 кг ≈ 2.20462 фунта;
- `pounds_to_kg(pounds)`.

- Функция `convert(value, mode="km_to_miles")` - обёртка с именованным аргументом по умолчанию. Она принимает значение и строковый ключ режима, а внутри вызывает нужную функцию через `if/elif`. Например:

- Функция `show_menu()` - просто печатает меню (ничего не возвращает).

- Функция `get_choice()` — запрашивает у пользователя пункт меню, проверяет корректность и возвращает число. При некорректном вводе - сообщение об ошибке.

## Задание "со звездочкой":

- Все результаты округляй до 2 знаков после запятой.
- Каждая функция должна иметь докстринг с описанием и примером.
- При некорректном вводе (буквы вместо числа) программа не должна падать — используй try/except.
- Реализуй выход по 0 корректно (через break или флаг).

## Пример работы:

```text
=== Конвертер величин ===
1. Километры -> мили
2. Мили -> километры
3. Цельсий -> Фаренгейт
4. Фаренгейт -> Цельсий
5. Килограммы -> фунты
6. Фунты -> килограммы
0. Выход

Выберите пункт: 3
Введите значение: 25
25 °C = 77.0 °F

Выберите пункт: 1
Введите значение: abc
Ошибка: введите число!

Выберите пункт: 0
До свидания!
```

_Подсказка_: для обёртки `convert` удобно использовать строковые ключи, совпадающие с именами режимов. Внутри можно сделать так:

```python
def convert(value, mode="km_to_miles"):
    if mode == "km_to_miles":
        return km_to_miles(value)
    elif mode == "celsius_to_fahrenheit":
        return celsius_to_fahrenheit(value)
    # ...
```
