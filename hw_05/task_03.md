# Задача 3. «Система голосования»

**Что нужно сделать**: написать программу для подсчёта голосов на выборах. Программа разбита на функции, демонстрирует работу с аргументами по умолчанию и возвратом значений.

## Обязательное задание

### Порядок работы программы:

- Пользователь вводит имена кандидатов (через запятую) - например, Аня, Боря, Вика.
- Программа создаёт список кандидатов (через `split()`).
- Далее пользователь вводит имена проголосовавших: по одному в строке. Ввод заканчивается словом стоп.
- Если введённое имя не совпадает ни с одним кандидатом - голос не учитывается, выводится предупреждение.
- После окончания голосования программа выводит результаты и определяет победителя.

### Требования к структуре кода:

- `create_candidates(raw_input)` - принимает строку с именами и возвращает список имён (через `split()` и `strip()`). Если список пуст - вернуть None.
- `register_vote(candidates, name)` - принимает список кандидатов и имя. Возвращает:
    - `True`, если голос засчитан (имя есть в списке кандидатов);
    - `False`, если имя не найдено.

- `count_votes(candidates, votes)` - принимает список кандидатов и список проголосовавших. Возвращает два списка одинаковой длины:
    - список имён кандидатов;
    - список количеств голосов, соответствующих им.

Например, для `candidates = ["Аня", "Боря"]` и `votes = ["Аня", "Аня", "Боря"]`:
`["Аня", "Боря"] и [2, 1]`.

- `find_winner(names, counts)` - принимает два списка и возвращает кортеж (имя_победителя, количество_голосов). Если несколько кандидатов набрали одинаковый максимум — вернуть список всех победителей и количество голосов.

- `print_results(names, counts, winner)` - печатает таблицу результатов и победителя. Ничего не возвращает.

- Функция с аргументом по умолчанию:
    - `print_results(names, counts, winner=None, title="Результаты голосования")` - если `winner` не передан (`None`), вывести только таблицу без строки победителя.

## Задание "со звездочкой":

- Обернуть основной цикл в `if __name__ == "__main__":`.
- Использовать `try/except` при вводе, если понадобится.
- Программа не должна падать, если кандидатов нет или никто не проголосовал.
- Каждая функция - с докстрингом, примером вызова и аннотацией типов.
- Обработать ничью (несколько победителей).
