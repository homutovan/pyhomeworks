# Задача 1. «Шифр Цезаря»

**Что нужно сделать**: написать программу, которая шифрует и расшифровывает текст с помощью простого шифра Цезаря - сдвига каждой буквы на `k` позиций вперёд по алфавиту.

## Порядок работы программы:

- Запросить у пользователя текст (любой, с пробелами и знаками препинания).
- Запросить сдвиг k (целое число, может быть отрицательным).
- Запросить режим: 1 - зашифровать, 2 - расшифровать.
- Вывести результат.

### Правила шифрования:

- Сдвигаются только буквы латинского алфавита (a–z и A–Z), регистр сохраняется.
- Пробелы, цифры и знаки препинания остаются без изменений.
- Сдвиг «зацикливается»: после `z` идёт a (используй `ord()` и `chr()`, а не готовый алфавит-строку).
- При расшифровке сдвиг применяется в обратную сторону.

## Задание "со звездочкой":

- после вывода результата покажи:
    - длину исходного текста;
    - количество букв латинского алфавита в нём;
    - результат в верхнем регистре (через `upper()`).

## Пример работы:

```text
Введите текст: Hello, World!
Введите сдвиг: 3
Режим (1 - шифровать, 2 - расшифровать): 1
Результат: Khoor, Zruog!
Длина текста: 13
Латинских букв: 10
В верхнем регистре: KHOOR, ZRUOG!
```

_Подсказка_: для буквы `c` сдвиг вычисляется так:

```text
base = ord('a') if c.islower() else ord('A')
new_c = chr((ord(c) - base + k) % 26 + base)
```

_Обрати внимание_ на операцию `% 26` - это и даёт «зацикливание». Используй методы `isalpha()`, `islower()`, `isupper()`.
