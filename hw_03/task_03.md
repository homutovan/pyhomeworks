# Задача 3. «Проверка на палиндром и "зеркальное" кодирование»

**Что нужно сделать**: написать программу, которая проверяет строку на палиндром и выполняет «зеркальное» преобразование символов.

## Обязательное задание

### Часть 1. Проверка на палиндром:

- Запросить у пользователя строку.
- Привести её к нижнему регистру (`lower()`).
- Удалить все пробелы и знаки препинания. Для этого пройди по строке циклом и оставь только буквы и цифры (проверяй через `isalnum()`). Собери новую строку через `join()` или конкатенацию.
- Сравнить очищенную строку с её перевёрнутой версией (`[::-1]`).
- Вывести «Это палиндром!» или «Это не палиндром».

### Часть 2. "Зеркальное" кодирование:

- Каждый символ очищенной строки заменить на символ, «зеркальный» ему по алфавиту: a <-> z, <->, <->, ..., <-> (для строчных латинских букв).
Для остальных символов (цифры, кириллица и т.д.) — оставить без изменений.

## Задание "со звездочкой":

### Часть 3. Дополнительный анализ:

- Вывести количество уникальных символов в строке.
- Вывести первый и последний символ исходной строки (через индексы).
- Вывести подстроку со 2-го по 5-й символ включительно (через срез). Если строка короче - вывести всю строку.

## Пример работы:

```text
Введите строку: А роза упала на лапу Азора
Это палиндром!
Зеркальный код: а роза упала на лапу азора
(для кириллицы символы не меняются)

Уникальных символов: 9
Первый символ: А
Последний символ: а
Срез со 2 по 5 символ:  роз
```

_Подсказка_: для «зеркального» преобразования используй `ord()`:

```text
если 'a' <= c <= 'z':
    new_c = chr(ord('z') - (ord(c) - ord('a')))
```

Для проверки, что символ - буква или цифра, используй `isalnum()`.Для кириллицы эта схема не подойдет - её оставляем как есть, или придумай рабочую схему.
