# Задача 2. «Ёлочка из звёздочек»

**Что нужно сделать**: написать программу, которая по введённой высоте H (целое число, 1 ≤ H ≤ 10) рисует «ёлочку» из символов *.

## Обязательное задание

Написать программу, которая должна:

- Запросить у пользователя высоту елочки.
- Если H вне диапазона - вывести сообщение об ошибке и завершить работу.
- Отрисовать с помощью символов "`*`" елочку указанной высоты.
- Правила построения:
    - В строке номер i (считая с 1) сначала идёт H - i пробелов, потом 2*i - 1 звёздочек.
    - После ёлочки выводится её «ствол»: строка из H - 1 пробелов и одной звёздочки.

## Пример работы:

```text
Введите H: 4

   *
  ***
 *****
*******
   *
```

## Задание "со звездочкой":

- После отрисовки посчитать и вывести общее количество звёздочек в ёлочке (без ствола).
