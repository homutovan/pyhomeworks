# Задача 1. «Списки покупок»

**Что нужно сделать**: написать программу, которая сравнивает два списка покупок, введённых пользователем, и помогает объединить их в один.

## Обязательное задание

### Порядок работы программы:

- Запросить у пользователя два списка покупок - каждый в виде строки с товарами через запятую.
Пример: молоко, хлеб, сыр, молоко, яйца.
- Преобразовать каждую строку в множество товаров (лишние пробелы убрать через `strip()`, регистр привести к нижнему через `lower()`).

- Вывести:
    - множество товаров из первого списка;
    - множество товаров из второго списка;
    - количество уникальных товаров в каждом.

- Что нужно посчитать с помощью операций над множествами:
    - Общие товары (есть в обоих списках) - через `&` или `intersection()`.
    - Товары только из первого списка - через `-` или `difference()`.
    - Товары только из второго списка через `-`.
    - Все товары (объединение) - через `|` или `union()`.
    - Товары, которые есть ровно в одном из списков (симметрическая разность) — через `^` или `symmetric_difference()`.

## Задание "со звездочкой":

- Проверить, являются ли списки одинаковыми (сравнить множества через `==`).
- Проверить, является ли первый список подмножеством второго (`<=` или `issubset()`), и наоборот.
- Вывести отсортированный список итоговых покупок (объединение, преобразованное в список и отсортированное).
- Спросить у пользователя товар и проверить, есть ли он в объединении (быстрая проверка через `in`).
