#Задача 3. «Инвентарь игрока»

**Что нужно сделать**: написать программу - инвентарь для компьютерной игры, где предметы хранятся в словаре, а их количество можно менять.

## Обязательное задание

### Структура данных:

- Словарь `inventory`, где ключ - название предмета, значение - количество (целое число).
- Множество `used_items` - предметы, которые персонаж уже использовал хотя бы раз.

### Меню программы:

```text
1. Добавить предмет
2. Использовать предмет
3. Удалить предмет из инвентаря
4. Показать инвентарь
5. Показать статистику
0. Выход
```

### Что должна делать каждая команда:

- Добавить предмет - запросить название и количество. Если предмет уже есть, увеличить количество (использовать `get()` для безопасного сложения). Если нет — добавить с указанным количеством.
- Использовать предмет - запросить название. Если предмета нет - сообщение об ошибке. Если есть и количество `> 0` - уменьшить на `1` и добавить в `used_items`. Если количество стало `0` - удалить предмет из инвентаря (`del` или `pop`).
- Удалить предмет - полностью убрать предмет из инвентаря (независимо от количества). Если предмета нет - сообщение.
- Показать инвентарь - вывести отсортированные по названию предметы с количеством. Если инвентарь пуст = соответствующее сообщение.

### Показать статистику:

- общее количество предметов (сумма значений через `sum(inventory.values())`);
- количество уникальных предметов (через `len(inventory)`);
- список всех названий предметов (через `keys()`, преобразованные в список и отсортированные);
- предмет с максимальным количеством (через `max()` с `key=inventory.get`);
- список использованных предметов (множество `used_items`, отсортированное);
- есть ли в инвентаре предмет с количеством больше `10` (через `any()` и генератор);
- все ли предметы имеют количество хотя бы `1` (через `all()` и генератор).

Каждое действие - отдельная функция.

## Задание "со звездочкой":

- Все названия предметов приводить к нижнему регистру и убирать лишние пробелы (`strip().lower()`).
- Проверять, что вводимое количество - положительное целое число (через `try/except` и проверку `> 0`).
- Программа работает в цикле `while True` до выбора `0`.

### Пример работы:

```text

Введите количество: 2
'зелье' теперь 5 шт.

Введите название предмета: зелье
Использовано 'зелье'. Осталось: 4 шт.

Выберите пункт: 4
```
