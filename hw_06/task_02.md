# Задача 2. «Телефонная книга»

**Что нужно сделать**: написать программу - мини-телефонную книгу с меню действий, использующую словарь для хранения контактов.

## Обязательное задание

### Структура данных:

- Словарь contacts, где ключ - имя (строка), значение — номер телефона (строка).
- Дополнительно - множество `favorites` с именами «избранных» контактов.

### Меню программы:

```text
1. Добавить контакт
2. Удалить контакт
3. Найти контакт
4. Показать все контакты
5. Добавить в избранное
6. Показать избранное
7. Показать статистику
0. Выход
```

### Что должна делать каждая команда:

- Добавить контакт - запросить имя и номер. Если имя уже есть - предложить заменить номер. Использовать `in` для проверки.
- Удалить контакт - запросить имя. Если контакта нет - вывести сообщение (через `get()` или `in`). Если удаляемый контакт был в избранном - тоже удалить его оттуда (`favorites.discard(name)`).
- Найти контакт - запросить имя. Использовать `get(name)` с сообщением «не найден», если нет.
- Показать все контакты - вывести отсортированные по имени контакты (через `sorted(contacts.items())`).
- Добавить в избранное - если контакт есть в словаре, добавить имя в множество `favorites`. Если нет - сообщение об ошибке.
- Показать избранное - вывести отсортированный список избранных контактов с номерами (используя `contacts[name]`).

### Статистика:

- общее количество контактов;
- количество избранных;
- список всех уникальных цифр, встречающихся в номерах (через множество);
- контакт с самым длинным номером (через `max()` с `key=len`).

Каждое действие - отдельная функция (например, `add_contact`, `remove_contact`, `show_contacts` и т.д.).

## Задание "со звездочкой":

- Для проверки корректности номера (только цифры, `+`, `-`, пробелы) используй простое условие или метод `replace()`.
- Программа работает в цикле `while True` до выбора `0`.
- Не падать при некорректном вводе - использовать `try/except` там, где нужно.

## Пример работы:

```text
=== Телефонная книга ===
1. Добавить контакт
...
Выберите пункт: 1
Введите имя: Аня
Введите номер: +7-900-123-45-67
Контакт Аня добавлен.

Выберите пункт: 5
Введите имя: Аня
Аня добавлен в избранное.

Выберите пункт: 7
=== Статистика ===
Всего контактов: 1
В избранном: 1
Уникальные цифры в номерах: {'0', '1', '2', '3', '4', '5', '6', '7', '9'}
Самый длинный номер: Аня (+7-900-123-45-67)

Выберите пункт: 0
До свидания!
```

_Подсказка_:

- Для добавления контакта: `contacts[name] = phone`.
- Для удаления: `del contacts[name]` или `contacts.pop(name)`.
