# Задача 1. «Умный калькулятор»

**Что нужно сделать**: усовершенствовать калькулятор из классной работы.


## Обязательное задание

Написать программу, которая должна:

- Запросить у пользователя два числа (могут быть дробными).
- Запросить знак операции: +, -, *, /.
- Вывести результат с пояснением, например: 12.5 + 3 = 15.5.

## Задание "со звездочкой":

- Если пользователь ввёл неизвестный знак - вывести сообщение об ошибке, и не считать.
- Если выбрано деление и второе число равно 0 - вывести «На ноль делить нельзя!».
- Если введено деление, результат выводится с двумя знаками после запятой.

## Пример работы:

```text
Введите первое число: 10
Введите второе число: 0
Введите операцию (+, -, *, /): /
На ноль делить нельзя!
```
