# Задача 2. «Перевод секунд в удобный формат»

**Что нужно сделать**: расширить задачу про минуты.

## Обязательное задание


Написать программу, которая запрашивает у пользователя количество секунд (целое число) и переводит количество часов, минут и секунд в следуюшем формате:

```text
X часов Y минут Z секунд
```

## Задание "со звездочкой":
- Если какая-то часть равна нулю, её не выводить (например, вместо «0 часов 5 минут 0 секунд» вывести «5 минут»).
- Если число секунд отрицательное — вывести сообщение об ошибке.

## Пример работы:

```text
Введите количество секунд: 3725
1 час 2 минуты 5 секунд
text
Введите количество секунд: 120
2 минуты
```
