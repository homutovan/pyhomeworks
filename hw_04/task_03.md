# Задача 3. «Библиотека: списки и кортежи»

**Что нужно сделать**: написать программу - мини-каталог книг.

## Обязательное задание

### Структура данных:

Каждая книга описывается кортежем: `(автор, название, год)`. Кортеж неизменяем - это важно, потому что данные книги менять не предполагается.

Каталог - это список кортежей. Список можно менять: добавлять, удалять книги.

### Порядок работы программы:

- Создать начальный каталог из 5 книг (придумай сама).
- Вывести каталог в удобном виде.
- Запросить у пользователя:

    - автора новой книги;
    - название;
    - год.

- Создать кортеж и добавить его в каталог через `append()`.
- Запросить у пользователя название книги для удаления. Найти её в каталоге и удалить. Если не найдена - вывести сообщение.

## Задание "со звездочкой":

- Отсортировать каталог по году издания (через `sort()` с параметром `key`). _Подсказка_: `key=lambda book: book[2]`.
- Найти самую старую и самую новую книгу (через `min()` и `max()` с тем же `key`).
- Посчитать общее количество книг и количество книг написанных после 2000 года (через генератор списка и `len()`).
- Вывести список всех авторов без повторов (используй ручную проверку через `in`).
- Развернуть каталог в обратном порядке (через `reverse()`).

```text
Книга добавлена.
```

_Подсказка_:

Для поиска и удаления используй цикл по каталогу:

```python
for i, book in enumerate(catalog):
    if book[1] == target:
        catalog.pop(i)
        break
```
